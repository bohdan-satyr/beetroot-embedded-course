# Модуль 2.5. Таймери: Як MCU точно відміряє час. Керування витяжним вентилятором на ESP32-S3 (ESP-IDF / PlatformIO)

Цей проект реалізує енергоефективну та надійну систему автоматичного керування витяжним вентилятором за допомогою мікроконтролера **ESP32-S3** у фреймворку **ESP-IDF** (середовище розробки **PlatformIO**).

## 📋 Опис завдання & Виконані вимоги

Необхідно було реалізувати циклічний таймер для витяжного вентилятора: **активна робота протягом 15 хвилин кожну годину**, з подальшим автоматичним вимкненням на 45 хвилин.

### Виконані технічні критерії:
*   **Апаратна комутація:** Вентилятор підключено як індуктивне навантаження через модуль реле `SRD-05VDC-SL-C`. Для узгодження логіки 3.3В (ESP32) та 5В (реле) інтегровано апаратний драйвер на базі NPN-транзистора.
*   **Незалежність від циклів:** Робота таймерів реалізована через високорівневі апаратні переривання **ESP Timer (High Resolution Timer)**. Вони працюють повністю автономно на рівні ОС.
*   **Без блокування процесора:** У коді **не використовується** функція `delay()` чи її аналоги. Процесор вільний для виконання інших задач.
*   **Без залучення тасок:** Цикл перемикання станів реалізовано через колбеки переривань. Головна функція `app_main()` завершується після ініціалізації периферії, робота програми продовжується **без участі нескінченних циклів `while(1)` чи FreeRTOS тасок**.
*   **Гнучке налаштування:** Інтервали часу роботи та відпочинку винесені у верхню частину коду у вигляді констант типу `const uint64_t`, що дозволяє легко масштабувати або динамічно змінювати конфігурацію системи.
*   **Налагодження системи:** Для зручності тестування реальні інтервали часу (1 год / 15 хв) пропорційно зменшені до тестових значень (10 сек відпочинку / 3 сек роботи).
*   **Візуальна індикація:** Додано світлодіодну індикацію поточного стану системи (Червоний колір — вентилятор відпочиває, Зелений — вентилятор працює) за допомогою вбудованого в плату розумного RGB-діода.

## 📂 Структура проекту

```text
.
├── components/          # Сторонні апаратні компоненти ESP-IDF
│   └── led_strip/       # Офіційний драйвер для роботи з WS2812B (NeoPixel)
├── result/              # Звіти, логи роботи пристрою та відеодемонстрація схеми
├── src/                 # Сирцеві файли проекту
│   ├── CMakeLists.txt   # Конфігурація збірки CMake для папки src
│   └── main.c           # Головний файл програми (ініціалізація, таймери, колбеки)
├── CMakeLists.txt       # Кореневий файл конфігурації CMake
├── platformio.ini       # Конфігураційний файл середовища розробки PlatformIO
└── README.md            # Опис проекту (цей файл)
```

## 🔌 Особливості підключення бібліотеки LED

Оскільки проект розробляється в середовищі **PlatformIO** з використанням фреймворку **ESP-IDF**, архітектура вимагала специфічного підходу до підключення офіційного компонента **`led_strip`** від Espressif для керування вбудованим RGB-світлодіодом (`WS2812B` на `GPIO 48`):

1. Було завантажено офіційний репозиторій драйвера `espressif/led_strip`.
2. Компонент інтегровано локально через створення кореневої папки `components/led_strip`.
3. Система збірки CMake в PlatformIO автоматично просканувала та скомпілювала бібліотеку без необхідності ручного редагування файлів `CMakeLists.txt` у папці `src`.
