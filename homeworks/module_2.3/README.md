# Модуль 2.3. Домашнє завдання: Superloop та незалежні задачі

Цей проєкт демонструє перехід з екосистеми Arduino на **ESP-IDF** (Espressif IoT Development Framework) з реалізацією неблокуючого керування кількома процесами в одному циклі. 

Програма керує трьома світлодіодами з різними інтервалами блимання без використання блокуючих затримок (`delay`), що є аналогом підходу `millis()` в Arduino, але оптимізовано під архітектуру **FreeRTOS**.

## 🚀 Особливості реалізації

1. **Заміна `millis()`**: Оскільки в чистому ESP-IDF немає функції `millis()`, поточний час зчитується в мілісекундах за допомогою `esp_timer_get_time() / 1000`.
2. **Зчитування стану піна**: Щоб працювала інверсія стану світлодіода за принципом `!gpio_get_level()`, піни GPIO налаштовані в режим подвійної дії: **`GPIO_MODE_INPUT_OUTPUT`**.
3. **Дружність до FreeRTOS**: В кінці нескінченного циклу додано обов'язковий `vTaskDelay(1)`. Це запобігає перевантаженню ядра процесора та уникненню спрацьовування сторожового таймера (**Task Watchdog Timer**).

## 📊 Інтервали та конфігурація GPIO

| Світлодіод | Пін GPIO | Інтервал блимання |
| :--- | :--- | :--- |
| **Червоний (RED)** | GPIO 5 | 200 мс |
| **Жовтий (YELLOW)** | GPIO 6 | 500 мс |
| **Зелений (GREEN)** | GPIO 7 | 1000 мс |

## 📂 Структура проєкту

Проєкт має стандартну структуру для зв'язки PlatformIO + ESP-IDF фреймворку:

```text
├── results/			  # Відео резуьтату роботи
├── CMakeLists.txt        # Корневий файл конфігурації CMake (ініціалізує ESP-IDF)
├── platformio.ini        # Конфігурація платформи PlatformIO (плата, фреймворк, швидкість порту)
├── src/
│   ├── CMakeLists.txt    # Файл реєстрації компонентів для CMake
│   └── main.c            # Основний вихідний код програми на мові C
└── README.md             # Документація проєкту
```

## 🛠️ Вимоги та налаштування

Для збірки та прошивки проєкту вам знадобляться:
* **VS Code** із встановленим розширенням **PlatformIO IDE**.
* Плата розробника на базі чипа **ESP32-S3** (за замовчуванням конфіг налаштований під `esp32-s3-devkitc-1`).

### Налаштування `platformio.ini`
Переконайтеся, що ваш файл конфігурації виглядає наступним чином:

```ini
[env:esp32-s3-devkitc-1]
platform = espressif32
board = esp32-s3-devkitc-1
framework = espidf
monitor_speed = 115200
```
