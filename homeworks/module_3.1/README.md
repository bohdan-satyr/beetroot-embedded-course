# Розумне керування освітленням на ESP32-S3 (ESP-IDF + C++)

Цей проєкт реалізує автоматичну систему керування світлодіодом залежно від рівня зовнішнього освітлення за допомогою фоторезистора (LDR). Проєкт написаний на **C++** з використанням фреймворку **ESP-IDF** у середовищі **PlatformIO**.

Логіка програми побудована на принципах об'єктно-орієнтованого програмування (OOP), математичної фільтрації сигналу та захисту від помилкових спрацьовувань.

## 🛠️ Функціонал системи
1. **Зчитування ADC у режимі Oneshot**: Використовується сучасний драйвер `esp_adc/adc_oneshot.h` з автоматичним визначенням аналогового каналу за номером GPIO.
2. **Фільтрація SMA (Simple Moving Average)**: Згладжування "шумів" датчика за допомогою фільтра ковзного середнього з вікном у 10 замірів.
3. **Двопороговий гістерезис**: Запобігає миготливості та мерехтінню світлодіода, коли рівень освітленості коливається на межі спрацьовування.

## 🗂️ Структура проєкту

*   **`include/`** — Заголовочні файли (`.hpp`), які описують інтерфейси (контракти) класів:
    *   `SmartLightController.hpp` — оголошення методів конфігурації GPIO та зчитування ADC.
    *   `SmaFilter.hpp` — оголошення кільцевого буфера та математики фільтрації.
*   **`src/`** — Реалізація логіки компонентів (`.cpp`) та головна точка входу:
    *   `SmartLightController.cpp` — ініціалізація заліза, безпечне вимкнення через деструктор.
    *   `SmaFilter.cpp` — обчислення ковзного середнього на базі `std::vector`.
    *   `main.cpp` — суперцикл програми (`app_main`), що координує роботу класів.
    *   `CMakeLists.txt` — конфігурація збірки для CMake.
*   **`media/`** — Фотографії зібраної схеми на макетній платі та демонстраційні відеоролики (процес закривання фоторезистора рукою та підсвічування ліхтариком).
*   **`result/`** — Логи роботи пристрою, зняті через `PlatformIO Serial Monitor`.
*   **`platformio.ini`** — Конфігураційний файл проєкту для PlatformIO.

## 🔌 Схема підключення (Дільник напруги)

Для вимірювання опору LDR використовується схема дільника напруги з постійним резистором на **10 кОм**.

### Фоторезистор (LDR):
*   **3.3V** (ESP32) ➡️ Перша ніжка LDR
*   **GPIO 4** (Аналоговий вхід ADC1) ➡️ Друга ніжка LDR
*   **GND** ➡️ Через резистор **10 кОм** до другої ніжки LDR (точка зняття сигналу)

### Світлодіод (LED):
*   **GPIO 5** ➡️ Резистор **220 Ом** ➡️ Анод LED (довга ніжка `+`)
*   **GND** ➡️ Катод LED (коротка ніжка `-`)

## 📉 Логіка роботи та Гістерезис

Програма працює за наступним алгоритмом:
*   Пристрій робить заміри кожні 50 мс.
*   На світлі опір LDR падає, значення ADC зростає (макс. 4095). У темряві опір зростає, значення ADC падає до 0.
*   **Поріг темряви (`THRESHOLD_DARK = 1500`)**: Якщо відфільтроване значення падає нижче 1500 — світлодіод вмикається.
*   **Поріг світла (`THRESHOLD_LIGHT = 2000`)**: Світлодіод не вимкнеться від випадкових коливань, поки рівень світла впевнено не перевищить 2000.

Лог роботи під час тестів збережено у папці `result/`.
