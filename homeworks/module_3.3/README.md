# Керування ШІМ (Світлодіод та Двигун) з однією кнопкою та АЦП на ESP32-S3

Цей проєкт демонструє реалізацію незалежного керування двома виконавчими механізмами — **яскравістю світлодіода** та **швидкістю обертання вала двигуна постійного струму** — за допомогою всього **одного потенціометра** та **однієї вбудованої кнопки**. Проєкт розроблено на мові **C++** у середовищі **PlatformIO** з використанням офіційного фреймворку **ESP-IDF (v5.x)**.

---

## 🕹️ Логіка роботи пристрою

Оскільки в системі є лише один фізичний потенціометр, інтерфейс побудовано на принципі перемикання режимів за допомогою вбудованої кнопки **BOOT**:

1. **Режим 1 (За замовчуванням): Керування СВІТЛОДІОДОМ**  
   * Обертання потенціометра плавно змінює яскравість світлодіода.  
   * Двигун при цьому зберігає свою попередню швидкість.
2. **Перемикання:** Натискання кнопки **BOOT (GPIO 0)**  
   * Система програмно відфільтровує брязкіт контактів (debouncing) та перемикає активний пристрій. Поточний стан виводиться в `Serial Monitor`.
3. **Режим 2: Керування ДВИГУНОМ**  
   * Тепер той самий потенціометр плавно регулює оберти вала двигуна.  
   * Світлодіод залишається світити з тією яскравістю, яку йому налаштували раніше.

## ⚙️ Технічні параметри периферії

| Модуль | Параметр | Значення | Опис / Конфігурація |
| :--- | :--- | :--- | :--- |
| **АЦП (ADC1)** | Режим / Канал | `Oneshot` / `Channel 3` | Потенціометр на **GPIO 4**. Зчитування за допомогою сучасного `adc_oneshot` API. |
| | Згасання (Atten) | `ADC_ATTEN_DB_12` | Дозволяє вимірювати повний діапазон напруги до 3.3 В. |
| | Розрядність | 12 біт (0 - 4095) | Скорочується бітовим зсувом `>> 2` до 10 біт для відповідності ШІМ. |
| **ШІМ (LEDC)** | Частота (Frequency) | 1000 Гц (1 кГц) | Оптимальна частота сигналів керування для світлодіода та двигуна. |
| | Роздільна здатність | `LEDC_TIMER_10_BIT` | Діапазон керування шпаруватістю (Duty Cycle) від 0 до 1023. |
| | Канали | `Channel 0` & `Channel 1` | Два незалежні канали, що працюють на спільному апаратному таймері. |
| **Кнопка** | Пін / Стан | `GPIO 0` (BOOT) | Працює в режимі `GPIO_MODE_INPUT` із внутрішньою підтяжкою `PULLUP`. |

## 🗂️ Структура проєкту

Проєкт організовано відповідно до стандартної структури PlatformIO для чистих ESP-IDF застосунків:

* 📁 **`src/`**
  * 📄 **`main.cpp`** — головний вихідний файл проєкту. Містить ініціалізацію таймерів ШІМ (`init_pwm`), налаштування АЦП одиничних замірів (`init_adc`), конфігурацію кнопки (`init_button`) та циклічну логіку в `app_main`.
* 📁 **`result/`** — фотографія зібраної схеми на макетній платі (Breadboard) та відеодемонстрація роботи пристрою, яка показує процес перемикання режимів кнопкою та незалежне регулювання світла і мотора.
* 📄 **`CMakeLists.txt`** — сценарій збірки проєкту для CMake.
* 📄 **`platformio.ini`** — конфігураційний файл середовища із зазначенням плати `esp32-s3-devkitc-1` та фреймворку `espidf`.

## 🔌 Схема підключення силової частини

Керування двигуном реалізовано за класичною безпечною схемою на базі біполярного транзистора **2N2222** та захисного діода **1N4007** для гасіння струмів самоіндукції обмоток:

```text
[ Зовнішнє Джерело 5В ] 
   ( + 5В ) ───────────────────────────────+───────────────+
   (  GND ) ───────+                       │               │
                   │                    [Двигун]     Діод 1N4007 (Смужка до +5В)
[ Плата ESP32-S3 ] │                       │               │
   (  GND ) ───────┴───────────────────────┼───────────────+
                                           │
   (GPIO 10) ───[ Резистор 1 кОм ]─── ( База B )
                                      (Колектор C) ─── Транзистор 2N2222
                                      ( Емітер E )
```

* **Світлодіод:** підключений до **GPIO 9** через струмообмежувальний резистор 220 Ом.
* **Потенціометр:** Крайні контакти підключені до `3.3V` та `GND` плати ESP32, середній сигнальний вивід — до **GPIO 4** (ADC1 Channel 3).

## 📋 Висновок за результатами дослідження

1. **Економічність інтерфейсу:** Проєкт довів можливість ефективного керування кількома параметрами за допомогою мінімальної кількості елементів керування (1 потенціометр + вбудована кнопка).
2. **Сумісність API:** Завдяки використанню сучасного типу ініціалізації через порожні структури (`= {}`) та актуальних констант `LEDC_TIMER_10_BIT` / `ADC_RTC_CLK_SRC_DEFAULT`, код повністю сумісний із найсуворішими правилами компіляції (`-Werror`) нових версій **ESP-IDF v5.x**.
3. **Безпека периферії:** Використання окремого живлення 5В для двигуна з об'єднанням ліній заземлення та встановлення зворотного діода повністю захистило кристал ESP32-S3 від індуктивних викидів та просідання напруги під час старту двигуна.
