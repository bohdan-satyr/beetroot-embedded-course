# 1:1 Servo Motor Control with Potentiometer for ESP32-S3 (ESP-IDF)

**Проєкт точного пропорційного керування положенням валу сервоприводу за допомогою потенціометра**, реалізований на базі фреймворку **ESP-IDF** (v5.3+) у середовищі **PlatformIO**. 

Програма написана на об'єктно-орієнтованому **C++**, не використовує Arduino framework і повністю оптимізована під архітектуру мікроконтролерів **ESP32-S3**.

## 🚀 Особливості реалізації
* **Апаратний ШІМ (LEDC):** Позиціонування сервоприводу здійснюється через вбудований периферійний контроллер на частоті 50 Гц із роздільною здатністю 14 біт, що забезпечує високу плавність ходу.
* **Автоматичне обчислення каналів АЦП:** Код позбавляє від необхідності вручну зіставляти GPIO з внутрішніми каналами АЦП. Функція `adc_oneshot_io_to_channel` автоматично визначає параметри на основі фізичного номера піна.
* **Пропорція 1:1 та фільтрація:** Алгоритм лінійно співвідносить увесь хід потенціометра з діапазоном 0–180° сервоприводу. Можливі виходи за рамки або шуми АЦП жорстко обрізаються функцією `std::clamp`.
* **Розумне логування:** Поточний кут відхилення від крайнього лівого положення виводиться в послідовний порт тільки в момент фізичної зміни положення ручки, запобігаючи забиванню консолі однаковими рядками.
* **Професійна C++ архітектура:** Проєкт чітко слідує правилу «Один клас — один файл». Константи, конфігурація АЦП та логіка сервоприводу повністю ізольовані в незалежних модулях.

---

## 📂 Структура проєкту

* **`include/Сonfig.hpp`** — Єдина точка конфігурації проєкту. Містить номери пінів, параметри таймерів ШІМ, межі імпульсів сервоприводу (в мкс) та роздільну здатність АЦП.
* **`include/ServoController.hpp`** — Оголошення класу `ServoController` для керування периферією LEDC.
* **`include/Potentiometer.hpp`** — Оголошення класу `Potentiometer` для роботи з однократним зчитуванням АЦП (`adc_oneshot`).
* **`src/ServoController.cpp`** — Реалізація ініціалізації таймера/каналів ШІМ та методу переведення кута в заповнення (Duty Cycle).
* **`src/Potentiometer.cpp`** — Реалізація автоматичного співвідношення GPIO з каналом, ініціалізація АЦП та функція мапування діапазонів.
* **`src/main.cpp`** — Точка входу `app_main`, яка зв'язує читання потенціометра та позиціонування сервоприводу в циклі з FreeRTOS-затримкою в 20 мс.
* **`src/CMakeLists.txt`** — Файл конфігурації збірки, що реєструє всі роздільні C++ модулі.

## 🔌 Схема підключення (Hardware)

Для реалізації проєкту необхідна плата **ESP32-S3-DevKitC-1**, потенціометр та сервопривід (наприклад, SG90) з **зовнішнім джерелом живлення 5V**.

## 🛠️ Налаштування середовища (`platformio.ini` & `CMakeLists.txt`)

Конфігурація PlatformIO під ESP32-S3 з використанням чистого фреймворку ESP-IDF (без залежностей від Arduino-бібліотек):

```ini
[env:esp32-s3-devkitc-1]
platform = espressif32
board = esp32-s3-devkitc-1
framework = espidf
monitor_speed = 115200
```

Для того щоб система збірки CMake знала про створені файли, ваш **`src/CMakeLists.txt`** має виглядати наступним чином:

```cmake
idf_component_register(SRCS "main.cpp" "ServoController.cpp" "Potentiometer.cpp"
                       INCLUDE_DIRS ".")
```

## 🔧 Калібрування крайніх положень

Різні моделі сервоприводів мають індивідуальні фізичні обмеження. Якщо при повороті потенціометра до упору ваш сервопривід впирається в механічний обмежувач і починає гудіти, скоригуйте тривалість імпульсів у мікросекундах всередині `include/Config.hpp`:

```cpp
// За замовчуванням задано широкий діапазон (500 - 2400 мкс)
constexpr uint32_t servoMinUs = 500;  // Кут 0° (Збільшіть, якщо серво гуде на початку)
constexpr uint32_t servoMaxUs = 2400; // Кут 180° (Зменшіть, якщо серво гуде в кінці)
```

## 📺 Результат роботи

При повороті потенціометра сервопривід синхронно повторює його кут у пропорції 1:1. В консоль виводяться структуровані логи:
```text
I (642) POT: Потенціометр ініціалізовано на GPIO 1 (Unit 0, Channel 0)
Кут відхилення: 0° (ADC: 0)
Кут відхилення: 45° (ADC: 1024)
Кут відхилення: 90° (ADC: 2048)
Кут відхилення: 180° (ADC: 4095)
```
