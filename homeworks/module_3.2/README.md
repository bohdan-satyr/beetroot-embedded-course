# Дослідження характеристик та калібрування АЦП на ESP32-S3

Цей проєкт демонструє роботу з Аналогово-Цифровим Перетворювачем (АЦП/ADC) мікроконтролера ESP32-S3 на мові **C++** за допомогою сучасного драйвера **ADC Oneshot**. Програма порівнює результати звичайного математичного обчислення напруги із заводською схемою калібрування **Curve Fitting Calibration (eFuse)**, виводячи результати в консоль у вигляді структурованої таблиці.

## 📊 Технічні параметри АЦП
Для забезпечення точних замірів у проєкті використовуються наступні апаратні конфігурації:

| Параметр | Значення | Опис |
| :--- | :--- | :--- |
| **Опорна напруга (\(V_{ref}\))** | ~1100 мВ | Внутрішнє базове джерело опорної напруги чіпа |
| **Атенюація (Загасання)** | `ADC_ATTEN_DB_12` | Вбудований дільник, що розширює вхідний діапазон до ~3.1 В |
| **Розрядність (Resolution)**| 12 біт | Дискретизація сигналу на рівні від 0 до 4095 (значення за замовчуванням) |
| **Схема калібрування** | **Curve Fitting** | Апроксимація кривою другого порядку на основі зашитих у eFuse коефіцієнтів |
| **Періодичність опитування**| ~100 мс | Інтервал між вимірами за допомогою функції `usleep()` з бібліотеки `<unistd.h>` |

---

## 🗂️ Структура лабораторної роботи
Проєкт оптимізовано та реалізовано в межах одного файлу для забезпечення лінійності й простоти аналізу коду без використання FreeRTOS та додаткових ООП-класів:

*   **`src/main.cpp`** — Ініціалізація периферії, конфігурація каналу АЦП через `adc_oneshot_unit_init_cfg_t`, підключення апаратного калібрування `adc_cali_create_scheme_curve_fitting()`, розрахунок похибки та циклічний вивід даних.
*   **`media/`** — Фото зібраної схеми (потенціометр ~10 кОм підключений як дільник напруги до ліній 3.3V, GND та вимірювального GPIO 4).
*   **`result/`** — Текстовий лог виведеної у консоль таблиці `RAW | U_manual | U_cali | Error(%)`.

---

## 📐 Методика розрахунку

1. **Мануальне обчислення (\(U_{manual}\))**:
   \[U_{manual} = \frac{RAW \times 3100}{4095}\]
   *Розрахунок базується на теоретичній лінійній пропорції, де максимальному значенню 4095 відповідає межа загасання в 3100 мВ.*

2. **Каліброване значення (\(U_{cali}\))**: Отримується через офіційний апаратний API `adc_cali_raw_to_voltage()`, який використовує індивідуальні заводські поправки конкретного кристала мікроконтролера.

3. **Похибка (Error %)**:
   \[\text{Error (\%)} = \frac{\vert{}U_{manual} - U_{cali}\vert{}}{U_{cali}} \times 100\%\]

### 🔬 Висновки дослідження
1. **Нелінійність і похибка:** Експеримент довів, що обчислення напруги за чистою лінійною формулою ($U_{manual}$) дає значну похибку від **10% до 17.7%** у робочому діапазоні. Це зумовлено нелінійністю внутрішньої характеристики АЦП.
2. **Мертві зони та насичення:** При напрузі вище ~3100 мВ значення АЦП фіксується на позначці **4095** (ефект кліппінгу), а реальна калібрована напруга досягає значення 3178 мВ.
3. **Ефективність калібрування:** Використання вбудованої схеми `Curve Fitting` дозволяє врахувати апаратні спотворення та отримати точні значення напруги, компенсуючи недоліки кремнієвої структури АЦП.
