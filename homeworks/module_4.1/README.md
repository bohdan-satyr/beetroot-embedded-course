# Bidirectional UART Communication: ESP32-S3 & STM32F4

**Двосторонній обмін даними по інтерфейсу UART між мікроконтролерами ESP32-S3 та STM32F411 (Black Pill)**, реалізований на мові **C++** у середовищі **PlatformIO**.

Проєкт демонструє кросплатформну взаємодію двох різних архітектур: **RTOS-орієнтованої ESP-IDF** на стороні ESP32-S3 та **bare-metal STM32Cube (HAL)** на стороні STM32F4 без використання додаткових радіомодулів чи конвертерів рівнів.

## 🚀 Особливості реалізації

* **Двостороннє керування в реальному часі:**
  * Натискання вбудованої кнопки `BOOT` (GPIO0) на **ESP32-S3** відправляє команду `'T'` та змінює стан синього світлодіода (`PC13`) на **STM32F4**.
  * Натискання вбудованої кнопки `KEY` (PA0) на **STM32F4** відправляє команду `'T'` та перемикає вбудований адресний RGB-світлодіод (`WS2812`) на **ESP32-S3**.
* **Генерація периферії через STM32CubeMX:** Базова конфігурація тактування, портів вводу-виводу (`GPIO`) та модуля `USART2` для STM32 згенерована у вигляді окремих модульних файлів (`.c/.h`), що залишає основну C++ логіку в `main.cpp` чистою та читабельною.
* **Апаратний RMT-драйвер для RGB LED:** Керування адресним світлодіодом WS2812 на ESP32-S3 реалізовано через апаратний модуль `RMT` (ESP-IDF) без сторонніх бібліотек та навантаження на процесор.
* **Пряме з'єднання 3.3 В:** Обидва мікроконтролери працюють на логічному рівні **3.3 В**, тому з'єднуються напряму трьома проводами (`TX`, `RX`, `GND`) без узгоджувачів рівнів.

## 📂 Структура проєкту

* **`esp32-s3/`** — Проєкт PlatformIO для плати **ESP32-S3-DevKitC-1** (фреймворк `espidf`, C++):
  * `src/main.cpp` — Ініціалізація `UART1`, опитування кнопки `BOOT`, прийом команд та C++ клас керування RGB-світлодіодом через `RMT`.
  * `platformio.ini` — Конфігурація збірки для ESP32-S3.
* **`stm32f4/`** — Проєкт PlatformIO для плати **Black Pill STM32F411CE** (фреймворк `stm32cube`, C++):
  * `include/` та `src/` (`gpio.c`, `usart.c`, `main.h` тощо) — Модулі ініціалізації периферії та `User Labels`, згенеровані через **STM32CubeMX**.
  * `src/main.cpp` — Точка входу (`extern "C" main`), опитування кнопки `PA0` та обробка вхідних байтів `USART2`.
  * `platformio.ini` — Конфігурація збірки та прошивки через програматор `ST-Link`.
* **`result/`** — Папка з фото/відеоматеріалами демонстрації фінальної збірки та тестування двостороннього зв'язку.
* **`README.md`** — Документація проєкту та схема підключення.

## 🔌 Схема підключення (Hardware)

Для роботи достатньо з'єднати обидві плати трьома проводами (лінії передачі даних підключаються навхрест: `TX` до `RX`):

> ⚠️ *Важливо:* Не з'єднуйте лінії живлення `5V` або `3V3` між платами, якщо кожна з них живиться від власного USB-кабелю. Обов'язковою є лише спільна земля (**GND**).

```text
       ESP32-S3 DevKit                        STM32F411 (Black Pill)
    ┌────────────────────┐                    ┌────────────────────┐
    │                    │                    │                    │
    │   GPIO 17 (TX1) ───┼────────────────────┼───► PA3 (RX2)      │
    │                    │                    │                    │
    │   GPIO 18 (RX1) ◄──┼────────────────────┼──── PA2 (TX2)      │
    │                    │                    │                    │
    │         GND     ───┼────────────────────┼──── GND            │
    │                    │                    │                    │
    └────────────────────┘                    └────────────────────┘
```

### Параметри UART (ідентичні на обох платах)
* **Швидкість (Baud Rate):** `115200 бод`
* **Формат кадру:** `8N1` (8 біт даних, без перевірки парності, 1 стоп-біт)
* **Апаратне керування потоком:** Вимкнено (`None`)

## 🛠️ Налаштування середовища (`platformio.ini`)

### Для ESP32-S3 (`esp32-s3/platformio.ini`)
```ini
[env:esp32-s3-devkitc-1]
platform = espressif32
board = esp32-s3-devkitc-1
framework = espidf
monitor_speed = 115200
```

### Для STM32F411CE (`stm32f4/platformio.ini`)
```ini
[env:blackpill_f411ce]
platform = ststm32
board = blackpill_f411ce
framework = stm32cube
upload_protocol = stlink
debug_tool = stlink
```

## 📺 Демонстрація роботи (Result)

У папці **`result/`** містяться матеріали, які демонструють роботу зібраного стенду:
1. Миттєве перемикання вбудованого синього світлодіода (`PC13`) на STM32F4 при натисканні кнопки `BOOT` на ESP32-S3.
2. Зміна стану адресного RGB-світлодіода (`GPIO48`) на ESP32-S3 при натисканні кнопки `KEY` на STM32F4.
3. Виведення діагностичних логів відправки та прийому команд у монітор порту (`Serial Monitor`) на стороні ESP32-S3.
