# ESP32 Morse Code Decoder

Проєкт на базі **ESP32**, який дозволяє вводити символи азбукою Морзе за допомогою кнопки та автоматично декодувати їх у ASCII-символи.

## Components

| Pin | Component | Description |
|-----|-----------|-------------|
| GPIO 18 | LED | Вмикається під час натискання кнопки |
| GPIO 5 | Button | Ввід крапки (`.`) або тире (`-`) залежно від тривалості натискання |
| GPIO 6 | Potentiometer | Регулювання швидкості введення (базового часу `T`) |
| GPIO 4 | Buzzer | Звуковий сигнал під час натискання кнопки |

## Features

- Визначення `.` та `-` за тривалістю натискання кнопки.
- Декодування Morse Code у латинські літери `A-Z` та цифри `0-9`.
- Автоматичне визначення меж символів і слів за тривалістю пауз.
- Регулювання швидкості введення потенціометром.
- Візуальний та звуковий зворотний зв'язок через LED і buzzer.
- Виведення введеного Morse Code та результату декодування через Serial Monitor.
