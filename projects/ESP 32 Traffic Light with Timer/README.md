# ESP32 Traffic Light with Timer

Проєкт на базі **ESP32**, який реалізує модель світлофора з дворозрядним 7-сегментним дисплеєм (спільний анод). Система працює на "голому залізі" (Bare Metal) без використання FreeRTOS та керується апаратним таймером (`gptimer`) для точного відліку часу та динамічної індикації.

## Components

| Pin | Component | Description |
| :--- | :--- | :--- |
| **GPIO 4** | LED Red | Червоний сигнал світлофора |
| **GPIO 5** | LED Yellow | Жовтий сигнал світлофора |
| **GPIO 6** | LED Green | Зелений сигнал світлофора |
| **GPIO 12** | DIG 1 | Катод/Анод першого розряду дисплея (десятки) |
| **GPIO 11** | DIG 2 | Катод/Анод другого розряду дисплея (одиниці) |
| **GPIO 16, 17, 9, 8, 18, 15, 7, 10** | SEG A-G, DP | Шина керування сегментами дисплея (A, B, C, D, E, F, G, DP) |

## Features

* **Bare Metal архітектура:** Логіка та таймінги побудовані виключно на апаратному таймері ESP32 та супер-циклі (`Super-Loop`), без залучення планувальника задач операційної системи.
* **Динамічна індикація:** Мультиплексування дисплея виконується з високою частотою (перемикання розрядів кожні 5 мс), що забезпечує чітке відображення чисел без мерехтіння для людського ока.
* **Автомат станів (State Machine):** Чітка логіка зміни фаз дорожнього руху (Червоний -> Червоно-Жовтий -> Зелений -> Зелений Блимаючий -> Жовтий).
* **Синхронний блінк:** Зелений сигнал та дисплей синхронно блимають наприкінці зеленої фази з частотою 2 Гц (кожні 500 мс).
* **Безпечна обробка ISR:** Обробник переривання таймера максимально полегшений і виконує лише інкремент лічильника системних тіків, запобігаючи паніці ядра (`Guru Meditation Error`).

## Project Structure

* `include/` — заголовочні файли конфігурації пінів та часових лімітів (`seven_segment_config.h`, `traffic_light_config.h`).
* `src/` — головний файл реалізації програми (`main.c`).
* `media/` — фотографії зібраного макета та демонстраційне відео роботи основних фаз світлофора (записано з прискореними фрагментами для наочності).
* `platformio.ini` / `CMakeLists.txt` — конфігураційні файли збірки проєкту.
