# 🔐 Interactive Hardware Safe Box for ESP32-S3 (ESP-IDF)

**Проєкт інтерактивного кодового сейфа з багаторівневою системою захисту**, реалізований на чистому фреймворку **ESP-IDF** (v5.x+) у середовищі **PlatformIO**. 

Програма написана на об'єктно-орієнтованому **C++**, не використовує Arduino framework, працює в одному високошвидкісному безтасковому циклі та повністю застрахована від збоїв сторожового таймера (Watchdog).

---

## 🚀 Особливості реалізації та геймплею

*   **Безтаскова динамічна індикація:** Робота 3-розрядного 7-сегментного індикатора реалізована через швидкі неблокуючі мікросекундні таймери (`esp_timer_get_time`). Це усуває конфлікти FreeRTOS та гарантує ідеальне світіння сегментів без мерехтіння.
*   **«Таймер вибуху» на потенціометрі:** Потенціометр динамічно задає ліміт часу на підбір коду від 10 до 60 секунд. За 3 секунди до блокування бузер починає тривожно пікати.
*   **Крок енкодера у 2 тики:** Налаштована підвищена чутливість ручки енкодера — цифри змінюються кожні два фізичні клацання, що захищає від механічного брязкання контактів.
*   **Механіка механічного реверсу:** Підтвердження поточної цифри коду та перехід до наступної реалізовано через **зміну напрямку обертання валу енкодера**, як у справжніх класичних сейфах.
*   **Криптографічний захист (FNV-1a 32-bit):** Правильні паролі зберігаються в прошивці у вигляді незворотних 32-бітних числових хеш-сум. Код неможливо прочитати у відкритому вигляді прямо з бінарного файлу.

## 📂 Структура проєкту

```text
include/
  ├─ Config.hpp         # Єдина точка конфігурації (піни, хеш-суми кодів)
  ├─ DisplayManager.hpp # Опис класу швидкої динамічної індикації
  ├─ Encoder.hpp        # Опис класу обробки імпульсів та реверсу енкодера
  ├─ Hardware.hpp       # Класи периферії: Кнопки, Бузер, Сервопривід, АЦП
  └─ SafeLogic.hpp      # Головний кінцевий автомат (State Machine) сейфу
src/
  ├─ DisplayManager.cpp # Неблокуючий перебір розрядів дисплея (tick)
  ├─ Encoder.cpp        # Програмний фільтр кроків та дебаунс кнопки SW
  ├─ Hardware.cpp       # Генерація нот через LEDC, ШІМ серво та АЦП-фільтрація
  ├─ SafeLogic.cpp      # Обробка логіки станів: IDLE -> SETUP -> INPUT -> SUCCESS/FAIL
  ├─ CMakeLists.txt     # Реєстрація C++ модулів для системи збірки
  └─ main.cpp           # Точка входу app_main з супер-циклом опитування
result/                 # Папка з матеріалами демонстрації фінальної збірки пристрою та результатами тестування.  
```

## 🔌 Схема підключення (Hardware)

Для збірки потрібна плата **ESP32-S3-DevKitC-1**, 3-розрядний 7-сегментний дисплей із **загальним анодом**, 3 PNP-транзистори (наприклад, BC557), енкодер KY-040, бузер, потенціометр, дві кнопки та сервопривід із **зовнішнім живленням**.

### Розподіл пінів (GPIO Layout):
*   **Потенціометр (Час):** GPIO 1 (ADC1_CH0)
*   **Сервопривід (Замок):** GPIO 2 (LEDC_CH0)
*   **Бузер (Звуки):** GPIO 21 (LEDC_CH1)
*   **Кнопка LVL (Рівень):** GPIO 38
*   **Кнопка START (Гра/Ввід):** GPIO 14
*   **Енкодер KY-040:** SW -> GPIO 4, DT -> GPIO 5, CLK -> GPIO 6
*   **Аноди дисплея (PNP):** Digit 1 -> GPIO 47, Digit 2 -> GPIO 15, Digit 3 -> GPIO 16
*   **Катоди дисплея (Сегменти):** A..G, DP -> GPIO 8, 9, 12, 11, 10, 18, 17, 13

## 🎮 Інструкція користувача (Алгоритм гри)

1.  **Старт:** При ввімкненні серво зачиняється (`0°`), екран показує тире `.---`. Крапка на 1-му розряді вказує на Рівень 1 (код з 1 цифри).
2.  **Налаштування:** Натисніть кнопку `LVL` для вибору складності (1, 2 або 3 цифри коду). Крапка переміститься на відповідний розряд.
3.  **Вибір часу:** Натисніть `START` один раз. Дисплей покаже час. Обертанням потенціометра виберіть ліміт на підбір від `010` до `060` секунд.
4.  **Злам сейфу:** Натисніть `START` вдруге. Запуститься зворотний відлік. На екрані з'являться нулі. Блимання крапки показує поточний розряд:
    *   Крутіть енкодер для зміни поточної цифри від 0 до 9.
    *   **Крутніть енкодер у зворотний бік (Реверс)**, щоб зафіксувати цифру та перейти до наступного розряду.
    *   *Натискання на кнопку енкодера (SW)* скидає набрані цифри поточної спроби.
5.  **Фінал:** Ввівши код, натисніть кнопку `START`.
    *   **Успіх:** Звучить мелодія перемоги, сервопривід відчиняє замок (`90°`).
    *   **Фейл (або вихід часу):** Звучить тривожна мелодія, екран гасне, сейф заблоковано.
6.  **Скидання:** В стані успіху натисніть кнопку енкодера `SW`, щоб знову зачинити сейф (`0°`) і повернутися до меню.

## 🛠️ Налаштування PlatformIO (`platformio.ini`)

Тулчейн налаштовано на збірку з оптимізацією за розміром (`-Os`), що робить завантажувач маленьким і повністю усуває конфлікти зміщення таблиць розділів пам'яті:

```ini
[env:esp32-s3-devkitc-1]
platform = espressif32
board = esp32-s3-devkitc-1
framework = espidf
monitor_speed = 115200
build_flags = -Os
```

## 🧮 Генерація власних секретних кодів

Хешування числових байтів масиву виконується за алгоритмом FNV-1a. Ви можете прописати будь-які коди в `include/Config.hpp`. Готові хеші для популярних числових комбінацій:

*   **Код `"5"`** (Рівень 1): `0x050c5d3f`
*   **Код `"53"`** (Рівень 2): `0x566a3879`
*   **Код `"539"`** (Рівень 3): `0x7c7569b9`
*   **Код `"123"`** (Рівень 3): `0x7c755efc`
*   **Код `"777"`** (Рівень 3): `0x7c756c66`
